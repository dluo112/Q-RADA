## 核心思路

有限的视觉 token 预算应如何分配给不同区域？查询相关性决定哪些区域值得保留，而区域的表示需求决定它们需要多少 token。例如，大物体可能用少量 token 就能表示，多个小目标则需要更多 token 保留细节。

Q-RADA 在多模态投影层之后、语言模型推理之前执行剪枝，保留预训练模型的参数：

1. **查询条件下的区域相关性评估**：划分视觉网格，使用冻结的视觉-文本编码器筛选候选区域。
2. **区域代表 token 的增量选择**：结合查询相关性、特征距离和空间距离构造嵌套代表集合。
3. **区域率失真建模**：测量不同区域 token 数量下的相关性加权特征失真。
4. **按边际收益分配预算**：将原始失真下降量转换为保守、非递增的代理收益，每次把下一个 token 分给当前收益最大的区域，直至用完全局预算 `B`。

在预算可行的条件下，贪心分配精确优化所构造的可分离代理目标；该结论适用于代理目标，而非模型最终回答的准确率。

## 主要实验结果

| 模型 | 保留的视觉 token | 相对综合得分 Avg.% |
| --- | --- | --- |
| LLaVA-1.5-7B | 192 / 576 | 99.7% |
| LLaVA-1.5-7B | 128 / 576 | 98.6% |
| LLaVA-1.5-7B | 64 / 576 | **97.1%** |
| LLaVA-NeXT-7B | 标称预算 640 | 100.6% |
| LLaVA-NeXT-7B | 标称预算 320 | 98.4% |
| Qwen2.5-VL-7B | 512 / 1,296 | 100.5% |
| Qwen2.5-VL-7B | 256 / 1,296 | 98.4% |
| Qwen2.5-VL-7B | 128 / 1,296 | 95.2% |

`Avg.%` 按论文原值保留，以各表的完整 token 模型为 100%。它不是原始基准分数的算术平均，也不是单项准确率。超过 100% 表示该综合指标超过对应基线，并不表示每项任务均提升。

### POPE 上的推理效率

以下结果均来自 LLaVA-NeXT-7B。视觉 token 数是样本组装后序列的平均值，与上表的标称预算口径不同。

| 方法 | 平均视觉 token | 平均延迟（秒） | P95 延迟（秒） | 加速比 | 峰值显存（GiB） | 准确率（%） | F1（%） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 完整 token 基线 | 2,280 | 0.33 | 0.40 | 1.00x | 15.03 | 86.80 | 86.40 |
| Q-RADA | 320 | 0.21 | 0.23 | 1.57x | 14.65 | 88.24 | 87.02 |
| **Q-RADA** | **175** | **0.17** | **0.18** | **1.87x** | **14.09** | **87.50** | **86.90** |
| Q-RADA | 80 | 0.15 | 0.17 | 2.20x | 13.89 | 86.93 | 86.31 |

从 2,280 降至 175，平均视觉 token 减少 **92.3%**。论文报告实验使用两张 NVIDIA RTX 4090 D；加速比根据未舍入的平均延迟计算，表中延迟仅展示两位小数。这些数据来自论文，本仓库暂未提供重新运行的结果。
